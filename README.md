# RADAR · Paquetes del laboratorio

Repositorio público exclusivo para paquetes binarios de ensayo de Windows y macOS.
No contiene el código fuente privado, datos de buzones ni credenciales personales.

RADAR consulta únicamente el catálogo firmado y descarga el paquete de su sistema,
sin iniciar sesión en GitHub. Toda actualización requiere aceptación del usuario.
La clave de publicación y la primera prueba en las instalaciones actuales están
pendientes de aprobación; todavía no hay Releases activables.
